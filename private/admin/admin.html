48-Hour Replay

Every broadcast message is logged to the history_log table and pruned after 48 hours, powering the frontend's scrollable timeline/scrubbing feature.

Replay Cache (RAM)

An in-memory mirror of history_log that serves replay reads without hitting SQLite, so many concurrent replay viewers don't contend with the live write path. Rebuilt from SQLite on every restart (the cache itself is volatile); disable via HISTORY_CACHE_ENABLED in main.py on memory-constrained servers.
